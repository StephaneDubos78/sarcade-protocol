# Modèle commun SARCADE v0.1

Cette première spécification définit les contrats minimaux nécessaires au MVP.

## Principes
- identifiants opaques et stables
- horodatages ISO 8601 en UTC sur le fil
- coordonnées WGS84 en degrés décimaux
- unités SI dans les champs techniques
- valeurs métier codées indépendamment de la langue d'affichage
- schémas versionnés
- champs non définis refusés en v0.1 afin de détecter les divergences tôt

## Objets
Event, Team, Device, Position, Message, ACK, POI et Gateway.

User sera spécifié avec le modèle d'identité/authentification afin d'éviter de mélanger identité, rôle opérationnel et données personnelles.

## Compatibilité bas débit
Les JSON Schema décrivent le modèle canonique. Ils ne préjugent pas du futur encodage compact radio. Un mapping binaire/CBOR pourra être défini sans changer la sémantique des objets.
